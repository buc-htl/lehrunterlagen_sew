# Competencies: Recursion

## Basic Understanding
- **Explain recursion concept**: Students can define recursion and explain how a function can call itself to solve a problem
- **Identify recursive vs. iterative approaches**: Students can recognize problems that are suitable for recursive solutions and compare them with iterative alternatives
- **Understand base cases**: Students can identify and implement base cases (termination conditions) that prevent infinite recursion

## Core Skills
- **Implement recursive functions**: Students can write recursive functions that correctly solve problems like factorial, fibonacci, and tree traversal
- **Trace recursive execution**: Students can manually trace through recursive function calls, understand the call stack, and follow the execution flow
- **Design recursive solutions**: Students can design and structure recursive algorithms for given problems, breaking down complex problems into smaller subproblems

## Problem Solving
- **Solve mathematical problems recursively**: Students can implement recursive solutions for mathematical problems (factorial, power, sum of series, etc.)
- **Handle recursive data structures**: Students can work with recursive data structures (trees, linked lists, graphs) using recursive algorithms
- **Implement divide-and-conquer algorithms**: Students can recognize and implement divide-and-conquer patterns using recursion (merge sort, quicksort, etc.)

## Analysis & Debugging
- **Analyze recursive complexity**: Students can analyze time and space complexity of recursive algorithms and understand stack depth implications
- **Debug recursive functions**: Students can identify and fix common recursion errors (missing base case, incorrect termination, stack overflow)
- **Optimize recursive solutions**: Students can recognize when tail recursion can be used or when memoization/dynamic programming can improve performance

## Advanced Concepts
- **Understand mutual recursion**: Students can implement functions that call each other recursively
- **Apply recursion with backtracking**: Students can implement backtracking algorithms for problems like the N-queens problem or maze solving
- **Recognize limitations**: Students understand when recursion is inefficient or inappropriate and can identify alternatives
