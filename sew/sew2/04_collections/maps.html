Was ist eine Map?

Definition

  • Eine Map speichert Daten als Schlüssel-Wert-Paare (Key-Value-Pairs).
  • Jeder Schlüssel kommt nur einmal vor.
  • Über den Schlüssel kann der zugehörige Wert schnell gefunden werden.
  • Auch bekannt als: Dictionary, Assoziatives Array, Hash Table

Konzeptionelles Beispiel Key/Value

Schlüssel (Key) Wert (Value)
"Anna Müller" "0664-1234567"
"Bob Schmidt" "0699-9876543"
"Clara Wagner" "0660-5551234"
"David Klein" "0676-7778888"

Über den Namen (Key) kann die Telefonnummer (Value) schnell gefunden werden.

Unterschied zu Listen und Sets

Liste (List)

  • Zugriff über Index (0, 1, 2, ...)
  • Reihenfolge ist wichtig
  • Doppelte Werte erlaubt
  • Gut für geordnete Sammlungen

Set

  • Keine Indizes
  • Reihenfolge meist unwichtig
  • Keine Duplikate
  • Gut für eindeutige Elemente

Map

  • Zugriff über Schlüssel (beliebiger Typ)
  • Reihenfolge meist unwichtig
  • Jeder Schlüssel nur einmal
  • Gut für Zuordnungen/Lookup

Typische Anwendungsfälle von Maps

1. Übersetzungen / Lookups

  • Ländercodes: "AT" → "Österreich"
  • Fehlercodes: 404 → "Not Found"
  • Abkürzungen: "ASAP" → "As Soon As Possible"
  • Wörterbücher: "hello" → "hallo"

2. Zählen von Vorkommen

  • Worthäufigkeit: "Java" → 42 (Anzahl der Vorkommen)
  • Charakterstatistiken: 'a' → 15
  • Votes: "Kandidat A" → 1234 Stimmen

// Beispiel: Wie oft kommt jedes Wort vor?
Map<String, Integer> wordCount = new HashMap<>();
wordCount.put("Java", 42);
wordCount.put("Python", 23);

3. Konfigurationen / Einstellungen

  • Settings: "theme" → "dark"
  • Environment Variables: "PATH" → "/usr/bin:/bin"
  • Properties: "database.url" → "jdbc:..."

4. Indizierung von Objekten

  • Matrikelnummer → Student
  • ISBN → Buch
  • ID → Datensatz

Map<String, Student> students = new HashMap<>();
students.put("12345", new Student("Max Mustermann"));
Student s = students.get("12345"); // Schneller Zugriff!

Maps in Java

Das Map Interface

  • Map ist ein Interface - nicht direkt instanziierbar
  • Wichtig: Im Gegensatz zu List und Set leitet Map nicht vom Collection Interface ab.
  • Wie bei List und Set gibt es verschiedene Implementierungen.
  • Generische Typangabe: Map<K, V> - K = Key (Schlüssel), V = Value (Wert)

import java.util.Map;
import java.util.HashMap;

Map<String, Integer> map = new HashMap<>();

Wichtigste Implementierungen

Klasse Eigenschaften Wann verwenden?
HashMap Schnell, keine Ordnung Standard-Wahl für die meisten Fälle
TreeMap Sortiert nach Schlüsseln Wenn Sortierung wichtig ist
LinkedHashMap Erhält Einfüge-Reihenfolge Wenn Reihenfolge beibehalten werden soll

HashMap

HashMap - Eigenschaften

  • Die am häufigsten verwendete Map-Implementierung
  • Basiert auf einer Hash-Tabelle
  • Sehr schneller Zugriff
  • Keine Garantie über die Reihenfolge der Elemente
  • Erlaubt null als Schlüssel und Wert

HashMap - Erstellen


import java.util.HashMap;
import java.util.Map;

//Keys sind Strings, Values sind Integers
Map<String, Integer> alter = new HashMap<>();

// Direkt als HashMap
HashMap<String, Integer> alter = new HashMap<>();

Tipp: Nutze das Interface Map als Typ für eine Unabhängigkeit von der konkreten Implementierung.

Wichtige Methoden


Map<String, Integer> alter = new HashMap<>();

// Einfügen
alter.put("Anna", 25);
alter.put("Bob", 30);

// Abrufen
int annaAlter = alter.get("Anna");  // 25

// Prüfen ob Schlüssel existiert
boolean vorhanden = alter.containsKey("Anna");  // true

// Prüfen ob Wert existiert
boolean hatWert = alter.containsValue(30);  // true

// Löschen
alter.remove("Bob");

// Größe
int anzahl = alter.size();  // 1

Vorsicht: get() kann null zurückgeben!


Map<String, Integer> alter = new HashMap<>();
alter.put("Anna", 25);

// Gefahr: NullPointerException!
int x = alter.get("Bob");  // Bob existiert nicht → null
                           // Wird zu int zugewiesen → Fehler!

// Besser: Erst prüfen
if (alter.containsKey("Bob")) {
    int bobAlter = alter.get("Bob");
}

// Oder: getOrDefault verwenden
int bobAlter = alter.getOrDefault("Bob", 0);  // 0 als Default

Über Map iterieren - Variante 1


Map<String, Integer> alter = new HashMap<>();
alter.put("Anna", 25);
alter.put("Bob", 30);
alter.put("Clara", 28);

// Über Schlüssel iterieren, keySet() gibt Set aller Schlüssel zurück
for (String name : alter.keySet()) {
    int age = alter.get(name);
    System.out.println(name + " ist " + age + " Jahre alt");
}

Über Map iterieren - Variante 2


// Über Einträge (Entry) iterieren (effizienter!)
for (Map.Entry<String, Integer> entry : alter.entrySet()) {
    String name = entry.getKey();
    int age = entry.getValue();
    System.out.println(name + " ist " + age + " Jahre alt");
}

Tipp: Diese Variante ist effizienter, da kein zweiter Lookup nötig ist.

Über Map iterieren - Variante 3


// Nur über Werte iterieren
for (Integer age : alter.values()) {
    System.out.println("Jemand ist " + age + " Jahre alt");
}

Hinweis: Hier haben wir keinen Zugriff auf die Schlüssel.

TreeMap

TreeMap - Eigenschaften

  • Elemente sind sortiert nach Schlüsseln
  • Zugriff etwas langsamer als HashMap
  • Schlüssel müssen vergleichbar sein (Comparable oder Comparator)
  • Erlaubt kein null als Schlüssel

TreeMap - Beispiel


import java.util.TreeMap;
import java.util.Map;

Map<String, Integer> noten = new TreeMap<>();
noten.put("Clara", 2);
noten.put("Anna", 1);
noten.put("Bob", 3);

// Ausgabe: Sortiert alphabetisch nach Namen!
for (String name : noten.keySet()) {
    System.out.println(name + ": " + noten.get(name));
}
// Anna: 1
// Bob: 3
// Clara: 2

Wann TreeMap verwenden?

  • Wenn die Schlüssel sortiert bleiben sollen
  • Für Bereichsabfragen (z.B. alle Einträge zwischen X und Y)
  • Wenn du die kleinsten/größten Schlüssel benötigst

TreeMap<Integer, String> map = new TreeMap<>();
map.put(3, "Drei");
map.put(1, "Eins");
map.put(5, "Fünf");

Integer first = map.firstKey();  // 1
Integer last = map.lastKey();    // 5

LinkedHashMap

LinkedHashMap - Eigenschaften

  • Behält die Einfüge-Reihenfolge bei
  • Etwas langsamer als HashMap
  • Nützlich wenn Reihenfolge wichtig ist, aber keine Sortierung

LinkedHashMap - Beispiel


import java.util.LinkedHashMap;
import java.util.Map;

Map<String, Integer> reihenfolge = new LinkedHashMap<>();
reihenfolge.put("Zweiter", 2);
reihenfolge.put("Erster", 1);
reihenfolge.put("Dritter", 3);

// Ausgabe: In Einfüge-Reihenfolge!
for (String key : reihenfolge.keySet()) {
    System.out.println(key);
}
// Zweiter
// Erster
// Dritter

Praktisches Beispiel

Worthäufigkeit zählen

Aufgabe

Zähle wie oft jedes Wort in einem Text vorkommt.


String text = "Java ist toll Java macht Spaß Java ist super";
String[] worte = text.split(" ");

Map<String, Integer> wordCount = new HashMap<>();

for (String wort : worte) {
    // Wenn Wort schon existiert: Zähler erhöhen
    // Sonst: Mit 1 beginnen
    if (wordCount.containsKey(wort)) {
        int count = wordCount.get(wort);
        wordCount.put(wort, count + 1);
    } else {
        wordCount.put(wort, 1);
    }
}

System.out.println(wordCount);
// {Java=3, ist=2, toll=1, macht=1, Spaß=1, super=1}

Elegantere Variante


String text = "Java ist toll Java macht Spaß Java ist super";
String[] worte = text.split(" ");

Map<String, Integer> wordCount = new HashMap<>();

for (String wort : worte) {
    // getOrDefault: Gibt 0 zurück wenn Schlüssel nicht existiert
    int count = wordCount.getOrDefault(wort, 0);
    wordCount.put(wort, count + 1);
}

Wichtige Hinweise

Schlüssel-Objekte müssen...

  • equals() und hashCode() korrekt implementieren
  • Immutable sein (sich nicht ändern)

// SCHLECHT! Listen ändern sich und sind nicht stabil
List<String> key = new ArrayList<>();
key.add("test");
map.put(key, "Wert");
key.add("mehr");  // Schlüssel ändert sich → Probleme!

// GUT: String, Integer, eigene immutable Klassen
String key = "test";
map.put(key, "Wert");

Vergiss nicht, dir die Codebeispiele anzusehen!

Zusammenfassung

  • Maps speichern Schlüssel-Wert-Paare
  • Jeder Schlüssel kommt nur einmal vor
  • HashMap: Schnell, keine Ordnung (Standard-Wahl)
  • TreeMap: Sortiert nach Schlüsseln
  • LinkedHashMap: Behält Einfüge-Reihenfolge
  • Wichtige Methoden: put(), get(), containsKey(), remove()
  • Anwendungsfälle: Lookups, Zählen, Caching, Indizierung
