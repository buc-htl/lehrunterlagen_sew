Ziele

  • Verstehen, wozu Iterators verwendet werden

  • Typische Fehler beim Arbeiten mit Iterators vermeiden

Problem: Collections durchlaufen

Wie können wir über alle Elemente einer Collection iterieren?


List<String> namen = new ArrayList<>();
namen.add("Anna");
namen.add("Bob");
namen.add("Clara");

// Bei ArrayList: Index verwenden
for (int i = 0; i < namen.size(); i++) {
    System.out.println(namen.get(i));
}

❌ Aber: Nicht alle Collections haben einen Index!

z.B. Set hat keine get() Methode

Lösung: Iterator

Ein Iterator ist ein Objekt, das...

  • über die Elemente einer Collection iteriert
  • unabhängig von der konkreten Collection-Implementierung funktioniert
  • sequentiellen Zugriff auf Elemente ermöglicht

Einheitliche Methode, um über alle Collections zu iterieren!

Iterator Interface

Das Iterator<E> Interface definiert folgende Methoden:

Methode Beschreibung
boolean hasNext() Gibt true zurück, wenn noch weitere Elemente vorhanden sind
E next() Gibt das nächste Element zurück und bewegt den Iterator weiter
void remove() Entfernt das zuletzt von next() zurückgegebene Element

Iterator erstellen

Jede Collection hat eine iterator() Methode:


List<String> namen = new ArrayList<>();
namen.add("Anna");
namen.add("Bob");
namen.add("Clara");

// Iterator erstellen
Iterator<String> iterator = namen.iterator();

💡 Muss importiert werden: import java.util.Iterator;

Iterator verwenden


List<String> namen = new ArrayList<>();
namen.add("Anna");
namen.add("Bob");
namen.add("Clara");

Iterator<String> iterator = namen.iterator();

while (iterator.hasNext()) {
    String name = iterator.next();
    System.out.println(name);
}

Ausgabe: Anna, Bob, Clara

Wie funktioniert es?

Iterator<String> it = namen.iterator();

▼ Iterator zeigt vor das erste Element

▼
[Anna, Bob, Clara]
it.hasNext() → true

✓ Es gibt ein nächstes Element

▼
[Anna, Bob, Clara]
it.next() → "Anna"

↓ Iterator bewegt sich weiter

[Anna] ▼ [Bob, Clara]
it.hasNext() → true
it.next() → "Bob"
[Anna, Bob] ▼ [Clara]
it.hasNext() → true
it.next() → "Clara"
it.hasNext() → false
[Anna, Bob, Clara] ▼

Iterator mit Set

Iterator funktioniert mit allen Collections:


Set<Integer> zahlen = new HashSet<>();
zahlen.add(42);
zahlen.add(15);
zahlen.add(8);

Iterator<Integer> iterator = zahlen.iterator();

while (iterator.hasNext()) {
    Integer zahl = iterator.next();
    System.out.println(zahl);
}

💡 Reihenfolge bei HashSet ist nicht garantiert!

Iterator vs. for-each

Mit Iterator


Iterator<String> it = 
    namen.iterator();

while (it.hasNext()) {
    String name = it.next();
    System.out.println(name);
}

Mit for-each




for (String name : namen) {
    System.out.println(name);
}

for-each verwendet intern einen Iterator! ✨

Wann braucht man Iterator?

for-each ist meistens besser lesbar. Iterator braucht man, wenn man:

  • Elemente während der Iteration entfernen möchte
  • mehrere Collections parallel durchlaufen will
  • die Iteration unterbrechen und später fortsetzen will

Elemente entfernen - FALSCH! ❌


List<String> namen = new ArrayList<>();
namen.add("Anna");
namen.add("Bob");
namen.add("Clara");

// NIEMALS während for-each entfernen!
for (String name : namen) {
    if (name.equals("Bob")) {
        namen.remove(name); // ❌ ConcurrentModificationException!
    }
}

💥 Wirft eine ConcurrentModificationException

Elemente entfernen - RICHTIG! ✓


List<String> namen = new ArrayList<>();
namen.add("Anna");
namen.add("Bob");
namen.add("Clara");

Iterator<String> iterator = namen.iterator();

while (iterator.hasNext()) {
    String name = iterator.next();
    if (name.equals("Bob")) {
        iterator.remove(); // ✓ Funktioniert!
    }
}

Ergebnis: [Anna, Clara]

remove() - Wichtige Regeln

  • remove() kann nur nach einem next() Aufruf verwendet werden
  • remove() kann nur einmal pro next() aufgerufen werden
  • Entfernt das zuletzt von next() zurückgegebene Element

Iterator<String> it = namen.iterator();
it.remove(); // ❌ IllegalStateException - kein next() davor!

it.next();
it.remove(); // ✓ OK
it.remove(); // ❌ IllegalStateException - zwei mal hintereinander!

Beispiel: Ungerade Zahlen entfernen


List<Integer> zahlen = new ArrayList<>();
zahlen.add(1);
zahlen.add(2);
zahlen.add(3);
zahlen.add(4);
zahlen.add(5);

System.out.println("Vorher: " + zahlen);

Iterator<Integer> iterator = zahlen.iterator();
while (iterator.hasNext()) {
    Integer zahl = iterator.next();
    if (zahl % 2 != 0) { // ungerade?
        iterator.remove();
    }
}

System.out.println("Nachher: " + zahlen);

Ausgabe: Vorher: [1, 2, 3, 4, 5] → Nachher: [2, 4]

Usecase : Parallel durchlaufen

Zwei Listen gleichzeitig durchlaufen:


List<String> vornamen = Arrays.asList("Anna", "Bob", "Clara");
List<String> nachnamen = Arrays.asList("Schmidt", "Müller", "Wagner");

Iterator<String> vornameIter = vornamen.iterator();
Iterator<String> nachnameIter = nachnamen.iterator();

while (vornameIter.hasNext() && nachnameIter.hasNext()) {
    String vorname = vornameIter.next();
    String nachname = nachnameIter.next();
    System.out.println(vorname + " " + nachname);
}

Ausgabe: Anna Schmidt, Bob Müller, Clara Wagner

💡 Mit for-each nicht möglich, da man nur über eine Collection iteriert

Usecase : Iteration unterbrechen

Iterator als Instanzvariable speichern und später fortsetzen:


List<Integer> daten = Arrays.asList(10, 20, 30, 40, 50);
Iterator<Integer> iterator = daten.iterator();

// Erste Verarbeitung - nur 2 Elemente
System.out.println("Teil 1:");
for (int i = 0; i < 2 && iterator.hasNext(); i++) {
    System.out.println(iterator.next());
}

// ... anderer Code ...

// Später fortsetzen
System.out.println("Teil 2:");
while (iterator.hasNext()) {
    System.out.println(iterator.next());
}

Ausgabe: Teil 1: 10, 20 → Teil 2: 30, 40, 50

ListIterator

Für Listen gibt es zusätzlich ListIterator<E>:

  • Erweitert Iterator<E>
  • Ermöglicht bidirektionale Traversierung (vor und zurück)
  • Zusätzliche Methoden: hasPrevious(), previous(), add(), set()

List<String> namen = new ArrayList<>();
namen.add("Anna");
namen.add("Bob");

ListIterator<String> listIterator = namen.listIterator();

Zusammenfassung

  • Iterator ermöglicht einheitlichen Zugriff auf alle Collections
  • Hauptmethoden: hasNext(), next(), remove()
  • for-each verwendet intern einen Iterator
  • Iterator notwendig zum sicheren Entfernen während Iteration
  • Niemals Collection direkt ändern während for-each!
  • ListIterator bietet erweiterte Funktionen für Listen

Best Practices

  • ✓ Verwende for-each, wenn du nur lesend iterierst
  • ✓ Verwende Iterator, wenn du Elemente entfernen musst
  • ✓ Prüfe immer mit hasNext() vor next()
  • ❌ Ändere Collection nicht direkt während for-each
  • ❌ Rufe remove() nicht ohne vorheriges next() auf
